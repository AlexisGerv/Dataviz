# Dataviz
Dataviz pour la SAE303 sur l'impact de l'IA sur les emplois et les entreprises

Les explications détaillées sont disponibles en cliquant sur l'icone ⤢ en haut à droite de chaque graphique.

Je me suis servi de l'IA  pour aider à comprendre comment créer des graphiques plus complexes comme la Heatmap ou le box plot étant donnée que la documentation de Plotly JS est assez difficile à comprendre.
Je m'en servais aussi de débuggeur.
L'IA m'a appris l'utilisation de ... en JS qui au final comme un require en PHP ce qui m'a été assez utile pour créer des mises en page et couleurs communes des graphiques
